# java-calculator-precourse

> 우아한테크코스 8기 프리코스 1주차, 문자열 덧셈 계산기

## 📝 구현할 기능 목록

1. **입력 처리**
   - 사용자로부터 문자열을 입력받는다.
   - 입력이 비어 있을 경우(""), 결과는 0으로 출력한다.
2. **구분자 처리**
   - 입력 문자열이 `//<delimiter>\n` 형식으로 시작하는지 확인한다.
      1. **기본 구분자 기준 문자열**
         - 기본 구분자(쉼표`,` 또는 콜론`:`)를 기준으로 문자열을 분리한다.
      2. **커스텀 구분자 기준 문자열**
         - 커스텀 구분자의 유효성을 검증한다.
         - `//<delimiter>\n` 형식인 경우, `<delimiter>`를 추출한다.
         - 추출한 `<delimiter>`를 기준으로 문자열을 분리한다.
3. **합계 계산**
   - 숫자의 유효성을 검증한다.
   - 검증된 숫자들을 모두 합한다.
4. **출력 처리**
   - 최종 계산 결과를 `결과 : n` 형식으로 콘솔에 출력한다.

## 🚨 예외 발생 상황 및 메시지

> 사용자가 잘못된 값을 입력한 경우 `IllegalArgumentException`을 발생시킨 후, 애플리케이션은 종료된다.

1. **공통**
   - 구분자를 연속으로 입력한 경우

     → `구분자를 연속으로 입력할 수 없습니다.`

   - 자연수 이외의 정수가 아닌 유리수, 0, 음의 정수를 입력한 경우

     → `자연수만 입력할 수 있습니다.`

2. **커스텀 구분자 적용 문자열**
   - 문자열 끝까지 `\n`을 입력하지 않은 경우

     → `\n을 입력해 커스텀 구분자 입력을 마쳐주세요.`

   - 두 글자 이상으로 커스텀 구분자를 지정한 경우

     → `두 글자 이상으로 커스텀 구분자를 지정할 수 없습니다.`

   - 기본 구분자를 커스텀 구분자로 지정한 경우

     → `기본 구분자(',', ':')를 커스텀 구분자로 다시 지정할 수 없습니다.`

   - 숫자를 커스텀 구분자로 지정한 경우

     → `숫자는 구분자로 지정할 수 없습니다.`

   - "" 혹은 " "와 같은 공백을 커스텀 구분자로 지정한 경우

     → `공백은 구분자로 지정할 수 없습니다.`

   - 지정되지 않은 구분자를 입력한 경우

     → `지정되지 않은 구분자가 포함되어 있습니다. 기본 구분자 또는 커스텀 구분자를 사용해주세요.`


## 🤔 기능 요구 사항에 기재되지 않은, 스스로 판단한 기준

1. **공통**
   - 구분자를 **연속**해서 입력할 수 없다.

       ```
       입력→ 1::2,3
       결과→ 예외 발생, 애플리케이션 종료
       ```

   - 숫자는 **자연수**만 취급한다. (정수가 아닌 유리수, 0, 음의 정수는 취급하지 않는다)

       ```
       입력→ 0.1:0.2:3
       결과→ 예외 발생, 애플리케이션 종료
       ```

2. **커스텀 구분자 적용 문자열**
   - 커스텀 구분자 설정 시에도 **기본 구분자 적용이 유효**하다.

       ```
       입력→ //@\n1@2:3
       결과→ 6
       ```

   - **두 글자 이상**으로 커스텀 구분자를 지정할 수 없다.

       ```
       입력→ //@@\n1@@2@3
       결과→ 예외 발생, 애플리케이션 종료
       ```

   - **기본 구분자**는 커스텀 구분자로 지정할 수 없다.

       ```
       입력→ //:\n1:2:3
       결과→ 예외 발생, 애플리케이션 종료
       ```

   - **숫자**는 커스텀 구분자로 지정할 수 없다.

       ```
       입력→ //5\n152:3
       결과→ 예외 발생, 애플리케이션 종료
       ```

   - "" 혹은 " "와 같은 **공백**은 커스텀 구분자로 지정할 수 없다.

       ```
       입력→ //\n12324
       결과→ 예외 발생, 애플리케이션 종료
       ```
